    Firebase の準備

    script.js 先頭の firebaseConfig を、Firebase コンソールのウェブアプリ設定に差し替えてください。Firestore を有効にし、テスト用なら次のルールを使えます。

    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
